# tRNA research For Su lab

本仓库整理 tRNA 相关研究材料，包括文献检索与阅读、分析流程、报告/PPT、图表资产、脚本和阶段性研究设想。

## 内容结构

| 路径 | 内容 |
| --- | --- |
| `biological functions and structural characteristics of tRNA/` | tRNA 生物学功能、结构特征、早期胚胎相关综述材料、文献阅读与 PPT 输出。 |
| `tRNA mod-fingerprint database/` | tRNA 修饰指纹库方向的文献、工具、数据库、代码仓库调研和分析输出。 |
| `tRNA analysis tools and algorithms/` | tRNA 分析工具与算法调研、报告和相关资源。 |
| `tRNA-related wet-lab experiments/` | tRNA 相关湿实验方向的文献、报告、图表和汇报材料。 |
| `tRNA_embryo_sperm_cryo_literature_20260604/` | 胚胎、精子、冻融/冷冻保存与 tRNA 修饰相关文献地图和项目设想。 |
| `analysis_induro_modification_fingerprints_20260602/` | Induro/MIM tRNA-seq 修饰指纹对比、文献精读和汇报输出。 |
| `new study/` | 新方向的阶段性材料。 |
| `scripts/` | 本地分析、绘图、材料生成相关脚本。 |
| `output/`, `outputs/` | 已生成的报告、图表、PPT 预览和中间整理结果。 |
| 根目录 PPT/PDF/图片 | 综合汇报、结构示意图和已整理材料。 |

## 上传范围说明

计划上传研究材料本体，包括 `.md`、`.pdf`、`.pptx`、`.py`、`.csv`、`.json`、图片、图表资产和已有输出。

不上传本地虚拟环境、`node_modules`、Python 缓存、Office 临时锁文件和本地环境变量文件；这些内容由 `.gitignore` 排除。

## 注意事项

- 仓库内包含下载的论文 PDF、网页 HTML、第三方工具仓库快照和示例数据。若目标仓库是公开仓库，建议确认这些材料的版权/许可证是否允许公开分发。
- 当前材料体量较大，排除虚拟环境、依赖目录和临时文件后约 901 MB；单个文件目前未超过 GitHub 100 MB 硬限制。
- 若后续继续加入大体量 PDF、PPT 或数据文件，建议考虑 Git LFS 或改用云盘/数据仓库保存原始大文件，在 GitHub 中保留索引和说明。
