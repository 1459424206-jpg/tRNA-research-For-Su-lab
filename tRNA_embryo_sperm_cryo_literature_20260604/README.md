# tRNA modification, embryo development, and sperm cryopreservation literature pack

检索日期：2026-06-04

这个资料夹围绕两个问题整理：

1. tRNA 丰富修饰在胚胎发育中应对哪些关键功能需求？
2. 如果成熟精子并非完全转录/翻译沉默，冷冻精子与新鲜精子的系统性差异是否可以从 tRNA/tRF/翻译层面切入？

文件：

- `01_literature_map_embryo_tRNA_modification.md`：胚胎发育中 tRNA 修饰和 tRNA 图谱重塑的功能地图。
- `02_project_ideas_fresh_vs_frozen_sperm_tRNA.md`：结合冷冻精子研究背景的可行课题设计。
- `references.tsv`：核心文献表，含链接、关键词和推荐用途。

一句话结论：

胚胎发育需要在极低 RNA 起始量、母源-合子转换、快速卵裂、细胞命运分化、氧化还原压力和线粒体代谢切换中维持精准翻译；tRNA 修饰通过稳定 tRNA、调节密码子解码、控制 tRNA 裂解为 tRF/tsRNA、影响特定蛋白翻译和胚胎表观遗传信息传递参与这些过程。对冷冻精子而言，最值得做的是“冷冻应激是否重塑精子 tRNA 修饰/tRF 货物，并进一步影响获能期翻译能力和早期胚胎 MZT/ZGA”。
